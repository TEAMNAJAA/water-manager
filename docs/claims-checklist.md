# Before a number goes into the slides or the video

| Claim | Allowed only when | Where the evidence lives |
|---|---|---|
| Meter-reading accuracy (any %) | measured on **real photos**, per condition, with the photo count | `ocr/reports/accuracy.md` → "Real photos" table |
| "IP65" | only for the bought enclosure, quoting the maker's rating | parts list |
| Flow rate from the dial needle | compared with a bucket and stopwatch on a real meter | hardware test log |
| Litres per day lost | always say "about" / "estimated"; it is night excess × 24 h | leak alert |
| Leak location | "to a soi (lane)", never "exact point" | night test |
| Cost per Clip | from real receipts / current Thai seller prices | `hardware/README.md` parts list |
| LINE OA / SMS gateway / smart-meter prices | checked with the provider in Thailand this month | your notes |
| ROI, money saved, water saved | only from pilot data in the real village | pilot report |
| Offline capacity, battery runtime | measured on the device | hardware test log |
| Simulated villages B, C, D (and A until the pilot) | always labelled "simulated" on screen and in voice-over | app shows the tag |
| "Open source" for the Clip reader | AI-on-the-edge-device is free for non-commercial use only; credit it, and say scaling uses NamJai's own MIT firmware or a commercial licence | [docs/field-test.md](field-test.md) |

Say plainly in the deck:

- NamJai finds leaks down to a soi, not an exact point.
- NamJai does not fix pipes – the technician network does.
- It only works if the local water committee and Tambon office take part.
- Water fees alone do not cover every cost; the local budget and network fund fill the gap.
